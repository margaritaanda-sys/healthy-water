## 🎯 Objetivo de la Solución
Plataforma web integral para la captación de clientes de **Healthy Water** en **León, Guanajuato (Zona Norte)**, con apertura de pedidos en 1 clic, diferenciación comercial para **Hogares** (pago en efectivo) y **Empresas** (crédito a 15/30 días con facturación CFDI), hoja de ruta optimizada para repartidores con control de capacidad física (límite 60 garrafones), asistente IA de reprogramación proactiva y dashboard de analíticas diarias.

---

## 🚀 Cómo Iniciar la Aplicación en tu Navegador

### Opción 1: Servidor Local Node.js
Desde la terminal en esta carpeta, ejecuta:
```bash
node server.js
```
Abre en tu navegador favorito:
👉 **[http://localhost:3000](http://localhost:3000)**

### Opción 2: Abrir directamente el archivo
Puedes hacer doble clic en `index.html` para abrirlo directamente en Chrome, Edge o Firefox.
