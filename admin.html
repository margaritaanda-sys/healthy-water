Arquitectura de Protección de Datos Personales

Healthy Water resguarda números telefónicos y ubicaciones domiciliarias de cientos de familias en León. El sistema implementa Row-Level Security (RLS) en Supabase, enmascaramiento dinámico de datos para choferes y tokens JWT de sesión generados por Clerk.

Cifrado DB: AES-256
Autenticación: Clerk JWT (15 min)
Retención PII: 12 meses máx.
Enmascaramiento Chofer: Habilitado
Tabla `orders` (RLS Activo)

Política que restringe la lectura de pedidos exclusivamente al personal con rol validado.

CREATE POLICY "Staff can view orders"
ON orders FOR SELECT
TO authenticated
USING (auth.jwt() ->> 'role' IN 
  ('admin', 'vendedora', 'repartidor'));
Enmascaramiento Chofer (PII)

Los números de teléfono se anonimizan en pantalla para evitar fugas de listas comerciales.

SELECT id, customer,
  CONCAT(SUBSTRING(phone, 1, 3), 
         '-***-', 
         SUBSTRING(phone, 7, 4)) AS masked_phone
FROM orders;
Depuración LFPDPPP (12 Meses)

Cron job automatizado en PostgreSQL que elimina coordenadas GPS y teléfonos antiguos.

SELECT cron.schedule(
  'purge-old-pii',
  '0 3 * * *',
  $$ UPDATE orders 
     SET phone = 'ANON', address = 'ARCHIVED' 
     WHERE created_at < NOW() - INTERVAL '1 year' $$
);
